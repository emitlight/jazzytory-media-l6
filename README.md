# jazzytory-media

[Jazzytory](https://emitlight.github.io/Jazzytory/) 오리지널 강의 영상 정적 호스팅(GitHub Pages).

- `v/<moduleId>.mp4` — 강의 영상 (1920×1080 H.264 · AAC, faststart)
- `v/<moduleId>.jpg` — 포스터
- `manifest.json` — 게시 목록

배경음악: Kevin MacLeod (incompetech.com), CC BY 4.0 — 곡명은 각 영상 끝 크레딧과 `manifest.json` 에 있다.
이 저장소는 게시 스크립트가 매번 단일 커밋으로 덮어쓴다(영상 이력이 git 에 쌓이지 않게).
